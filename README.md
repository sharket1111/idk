# Rhythm Brawl (가제)

박자에 맞춰 싸우는 **리듬 대전 격투** 게임입니다. 귀여운 치비 픽셀 캐릭터들이 음악에 맞춰 주고받으며 싸웁니다.
HTML5 Canvas, Web Audio, 순수 JavaScript로 만들었고 빌드 도구가 필요 없습니다.

## 실행

```bash
python3 -m http.server 8000    # 또는: npx serve
```
브라우저에서 http://localhost:8000 을 열고 **Enter**(또는 화면 클릭)를 누르세요. 브라우저 정책 때문에 소리는 키 입력이나 클릭을 한 뒤에 켜집니다.

## 규칙

턴 하나는 2마디이고, 공격과 방어가 번갈아 옵니다.

1. **공격 마디**: 공격자가 흘러오는 노트에 맞춰 펀치(♥)와 킥(★)을 누릅니다. 정확도만큼 공격이 장전됩니다. 놓친 노트는 공격이 나가지 않습니다.
2. **방어 마디**: 장전된 공격이 바로 다음 마디에 **같은 리듬으로** 날아옵니다(하늘색 테두리 노트). 방어자는 같은 버튼으로 막습니다.
   - PERFECT: 패링, 피해 없음 / GREAT: 피해 25% / GOOD: 피해 50% / MISS 또는 다른 버튼: 피해 100%
3. 턴마다 공격과 방어가 바뀌고, 두 턴마다 리듬이 어려워집니다.
4. 체력이 0이 되면 K.O.이고, 먼저 2라운드를 이기면 승리합니다.

| | P1 | P2 |
|---|---|---|
| 펀치 (♥, 위 레인) | D | J |
| 킥 (★, 아래 레인) | F | K |

CPU를 상대할 때는 P1이 J/K도 쓸 수 있습니다.

- **타이틀 화면**: F2/F4 캐릭터 변경, F1 P2를 CPU 또는 사람으로 전환
- **[ / ]**: 싱크 조절. 판정이 늘 늦게(또는 빠르게) 나오면 5ms씩 맞춥니다. 값은 브라우저에 저장됩니다.

## 구조

```
src/
  main.js        진입점, 화면 확대, 게임 루프
  config.js      BPM, 판정 범위, 피해량 등 상수
  audio.js       Web Audio 음악/효과음 합성 + 오디오 시계 (heardTime)
  input.js       키 입력 시각을 오디오 시간으로 기록
  chart.js       난이도별 공격 패턴 생성, CPU 판정
  game.js        타이틀/대전/결과, 턴 진행, 판정, 피해 계산
  track.js       하단 리듬 트랙 (노트, 판정선, 박자선)
  fighter.js     캐릭터 상태 (체력, 애니메이션, 돌진)
  chibi.js       코드로 그리는 치비 픽셀 캐릭터 (24x22 머리, 표정, 포즈)
  characters.js  캐릭터 정의 (팔레트 + 머리 장식)
  stage.js       배경
  effects.js     타격 이펙트 (별, 하트)
  hud.js         체력바, 박자 하트, 텍스트
```

### 핵심 개념
- **오디오 시계**: 모든 노트 시간과 판정은 `AudioContext` 시간을 기준으로 합니다. 화면 프레임 기준으로 판정하면 최대 16ms가 어긋납니다. `getOutputTimestamp()`로 지금 스피커에서 들리는 시간을 계산합니다.
- **입력 시각 기록**: 키를 누른 순간의 `event.timeStamp`를 오디오 시간으로 바꿔서 큐에 쌓고, 프레임마다 판정합니다.
- **음악 스케줄러**: 25ms마다 0.15초 앞의 음을 미리 예약합니다. 음원 파일 없이 합성하므로 저작권 걱정이 없습니다.

## 캐릭터
MOMO, YUKI(오리지널), ALICE(이상한 나라의 앨리스), HOOD(빨간 망토), WUKONG(서유기)
- 2등신보다 조금 짧은 다리, 24x22 머리, 3x4 크기의 눈
- 표정: 미소, 깜빡임, 공격할 때 입 벌림, `> <`, `^ ^`, `x x`
- 새 캐릭터는 `characters.js`에서 팔레트와 장식(`bun`, `ribbon`, `clip`, `longHair`, `circlet`, `tail`)을 조합해 만듭니다.
