# Pixel Fighter (가제)

2D 횡스크롤 픽셀 파이팅 게임의 기초 틀입니다. HTML5 Canvas와 순수 JavaScript로 만들었고, 빌드 도구나 설치할 것이 없습니다.

## 실행

ES 모듈을 쓰기 때문에 `index.html` 파일을 더블클릭하면 실행되지 않고, 로컬 서버가 필요합니다.

```bash
python3 -m http.server 8000    # 또는: npx serve
```
그다음 브라우저에서 http://localhost:8000 을 엽니다.

## 조작

| | P1 | P2 |
|---|---|---|
| 이동 | A / D | ← / → |
| 점프 | W | ↑ |
| 앉기 | S | ↓ |
| 약공격 | J | , |
| 강공격 | K | . |

- **가드**: 상대의 반대 방향을 누릅니다. 하단 공격은 앉아서, 점프 공격은 서서 막아야 합니다.
- **F1**: P2를 CPU와 사람 사이에서 전환합니다 (기본값은 CPU).
- **F3**: 히트박스를 표시합니다 (초록 = 피격 판정, 빨강 = 공격 판정).
- **Enter**: 매치가 끝난 뒤 다시 시작합니다.

## 구조

```
index.html            캔버스 + 조작 안내
src/
  main.js             진입점, 고정 60fps 게임 루프, 정수배 화면 확대
  config.js           해상도, 중력, 라운드 시간 등 상수
  input.js            키보드 입력 / 컨트롤러 인터페이스 / 간단한 CPU
  game.js             라운드 흐름, 타격 판정, 히트스톱, 카메라, 그리기 순서
  fighter.js          캐릭터 상태 머신, 물리, 히트박스와 허트박스, 가드
  moves.js            기술 프레임 데이터 (발생/지속/후딜, 데미지, 경직...)
  characters.js       캐릭터 정의 (이름, 팔레트, 능력치, 기술, 스프라이트)
  render-fighter.js   캐릭터 그리기 (스프라이트가 없으면 임시 픽셀 캐릭터)
  sprite.js           스프라이트 시트 애니메이션 재생
  stage.js            패럴랙스 배경
  effects.js          히트 스파크, 가드 이펙트
  hud.js              체력바, 타이머, 승리 표시, 메시지
assets/               직접 그린 그림을 넣을 폴더
```

### 핵심 개념
- **고정 타임스텝**: 로직은 항상 1/60초 단위로 돌아갑니다. 그래서 모든 기술 수치를 "프레임"으로 정할 수 있습니다.
- **상태 머신**: `idle / walk / crouch / jump / attack / hitstun / blockstun / knockdown / ko`
- **프레임 데이터** (`moves.js`): `startup`(발생) → `active`(판정) → `recovery`(후딜). 판정이 나오는 동안만 히트박스가 생깁니다.
- **히트스톱**: 공격이 맞는 순간 몇 프레임 멈춰서 타격감을 줍니다. KO 때는 길게 멈춥니다.
- **컨트롤러 추상화**: 키보드와 CPU가 같은 `held()/pressed()` 인터페이스를 씁니다. 게임패드나 온라인 입력도 같은 방식으로 붙이면 됩니다.

## 직접 그린 픽셀아트 넣기
1. 오른쪽을 바라보는 캐릭터 스프라이트 시트를 `assets/`에 넣습니다. 한 줄에 애니메이션 하나씩 배치합니다.
2. `characters.js`의 `sprite: null` 부분에 설정을 넣습니다. 예시는 `src/sprite.js` 위쪽 주석에 있습니다.
3. 애니메이션 이름은 상태 이름(`idle`, `walk`, `jump`, `hitstun` 등)이나 기술 이름(`standLight` 등)을 씁니다.
4. 그림을 넣은 뒤 F3을 켜고, 그림에 맞게 `moves.js`의 히트박스를 조정하세요.
